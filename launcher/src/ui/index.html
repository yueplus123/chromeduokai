Chrome 分身启动器

还没有分身

点右上角「新建分身」选择数据文件夹,或用「扫描文件夹」批量添加。

卡信息用 Windows 系统加密保存在本机。在这里统一管理所有卡,并勾选每张卡用于哪些分身;对应分身的卡片上就会出现一键复制按钮。

卡库是空的

点右上角「＋ 添加卡片」录入第一张卡。

在这里添加买来的代理账号(如 IPRoyal 住宅代理),密码用 Windows 系统加密保存在本机。然后在分身的「编辑」里选择用哪个代理、哪个国家。启动时会自动查出口 IP,并把浏览器的语言和时区改成 IP 所在地。

IP 池是空的

点右上角「＋ 添加代理」,把代理后台给的那一行粘贴进来即可。
